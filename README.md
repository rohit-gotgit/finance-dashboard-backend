# Finance Backend

## Features
- JWT Authentication
- Role-based Access Control
- Transaction CRUD
- Dashboard Analytics

## Roles
- Viewer: Read only
- Analyst: Read + dashboard
- Admin: Full access

## Tech
- Node.js
- Express
- MongoDB

## APIs
POST /api/auth/register
POST /api/auth/login
GET /api/transactions
POST /api/transactions
GET /api/transactions/dashboard
